# 抗恶意参与方的联邦学习模拟框架（Robust-FL）

模拟 **10 家医院** 在数据不出院、仅交换模型更新的联邦训练中，面对单家作恶、
隐蔽定向攻击与多家合谋时，8 种聚合/防御策略的实际效果。

## 1. 要回答的问题

1. 一家医院被攻破后上传破坏性更新，全局模型会不会崩？
2. 攻击者只让某一类病例（如某病种）判断变差、整体准确率几乎不动，能不能防住？
3. 作恶方把更新的范数和方向伪装得像正常的非 IID 漂移，检测还成立吗？
4. 3～4 家医院合谋、上传高度雷同的更新，Krum 这类"靠两两距离投票"的防御会不会失效？
5. 防御在**没有攻击**时会不会误伤正常医院（非 IID 下的假阳性）？

## 2. 目录结构

```
robust_fl/
├── data.py          合成影像数据、Dirichlet 非 IID 医院切分、投毒数据集
├── model.py         两层小 CNN（约 2 万参数）+ 参数扁平化工具
├── attacks.py       5 类攻击更新构造（自适应范数伪装）+ 良性基线
├── aggregators.py   8 种聚合器，含自研分层防御 AdaGuard
├── simulation.py    联邦轮次循环、本地训练、评估指标（含后门 ASR）
├── plotting.py      逐轮曲线、跨场景柱状图、CSV 汇总
└── run_experiments.py  实验入口（6 场景 × 8 聚合器）
```

## 3. 运行方式

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

.venv/bin/python -m robust_fl.run_experiments --smoke   # 2 轮快速冒烟，约 5 分钟
.venv/bin/python -m robust_fl.run_experiments           # 完整实验（默认 35 轮）
.venv/bin/python -m robust_fl.run_experiments --rounds 20
```

输出在 `results/`（冒烟为 `results_smoke/`）：

- `summary.csv`：全部 48 组的最终/尾部准确率、受害类召回、后门 ASR、检测 TPR/FPR
- `hospital_distribution.png`：10 家医院 × 6 类别的非 IID 样本分布热力图
- `curves_<场景>.png`：每个场景下 8 条聚合器的逐轮准确率与受害类指标曲线
- `bar_<指标>.png`：跨场景分组柱状图（尾部 5 轮平均）
- `results.json`：完整逐轮数据 + 各方法理论容忍度
- `report.md`：自动生成的 Markdown 对比报告与综合排名

## 4. 数据与非 IID 设定

- 合成 6 类"影像"（16×16）：每类有独立空间位置的高斯亮斑 + 类特异性朝向/频率
  条纹 + 高斯噪声，小 CNN 必须学到真实特征才能区分；
- 10 家医院按 **Dirichlet(α=0.3)** 切分，配额 <5% 的类别直接缺失，
  模拟专科医院与地区病谱差异（冒烟输出可见医院 5 只有第 5 类、医院 8 只有 2 类）；
- 服务器持有 300 张 IID 可信小数据集（模拟公开基准/外购脱敏数据），
  用于训练 FLTrust/AdaGuard 的"根更新"锚点，不与任何医院数据重叠。

## 5. 攻击场景（攻击者能力按偏强的自适应模型设定）

攻击者能观测本轮良性更新、知道防御使用的范数中位数统计，并据此伪装。

| 场景 | 攻击 | 恶意比例 | 构造方式 |
|---|---|---|---|
| S0 | 良性基线 | 0% | — |
| S1 | 高斯噪声 | 30% | 范数 = 良性中位数 ×3 的随机方向更新 |
| S2 | 符号翻转 | 20% | 良性中位数反方向 ×2 范数 |
| S3 | 后门 | 30% | 右下角 3×3 触发器 → 目标类，范数伪装到 1.5× 中位数 |
| S4 | **隐蔽定向** | 30% | 标签翻转（只翻受害类）+ 35% 向良性中位数混合 + 1.2× 范数伪装 |
| S5 | **4 家合谋** | 40% | 共享攻击方向、彼此仅 2% 抖动形成紧密簇，超过 Krum 的 f 假设 |

S4 是题述"只让某一类变差、整体准确率看不出来"的直接建模；
S5 用于击穿 Krum/多 Krum 的理论前提（恶意方 ≥ (n-2)/2 时投票被合谋簇接管）。

## 6. 防御策略与分层设计

| 聚合器 | 机制 | 层 |
|---|---|---|
| fedavg | 无防御基线 | — |
| clip_avg | 中位数范数 ×2 裁剪后平均 | L1 |
| krum | 两两距离平方和投票，选最不孤立的 1 个 | L3 |
| multi_krum | 迭代 Krum 选 n−f 个再平均 | L3 |
| trimmed_mean | 坐标级每侧截 1 个极值 | L3 |
| coord_median | 坐标级中位数 | L3 |
| fltrust | 根更新余弦信任分 ReLU 加权 + 根范数对齐 | L2 |
| **adaguard** | 四层串联（见下） | L1+L2+L3+L4 |

### AdaGuard（本项目自研）的四层流水线

1. **L1 范数层**：逐更新裁剪到中位数范数 ×2，大范数冲击直接失效；
2. **L2 方向层**：与服务器根更新算余弦，`trust = ReLU(cos)`，
   与根反向的更新权重归零——定向攻击的主防线；
3. **L4 簇上限**：余弦 >0.90 贪心聚类，任一簇总权重 ≤ 2/n。
   4 家合谋者无论多少人，聚合时只顶 2 票，削掉的权重按比例返还其余簇；
4. **L3 加权坐标截断**：按权重在每个坐标截掉两侧各 10% 累积质量，
   吸收非 IID 良性漂移中的离群坐标，并清除后门残余分量；
5. **软步长上限**：聚合更新范数超过根更新 ×2 才回缩（不做强制等长）。

关键消融结论（见 `results/` 与报告）：

- 去掉 L3：后门 ASR 0 → 0.53；去掉全部步长约束：ASR → 0.98；
- 把软上限换成 FLTrust 的精确根范数对齐：良性准确率 0.978 → 0.948。
  软上限 + L3 是同时保住良性精度与后门防御的最小组合。

### 为什么正常的"不一样"不会被当成作恶

非 IID 医院的更新在方向上仍与根更新正相关（数据不同但任务相同），
L2 的 ReLU 余弦不会给零分；L1 用的是**本轮自适应中位数**而非固定阈值，
整体尺度漂移不触发裁剪；L3 是坐标级统计而非客户端级剔除，
单个医院的偏斜只影响少数坐标。检测假阳性率（FPR）由实验量化给出。

## 7. 评估指标

- **全局准确率**：整体可用性；
- **受害类召回 / 最差类召回**：暴露"整体看不出、单类被打穿"的隐蔽攻击；
- **后门 ASR**：带触发器样本被误判到目标类的比例；
- **检测 TPR/FPR**：聚合器标记的异常客户端与真实恶意标签对照
  （标签只用于事后统计，不进入防御逻辑）。

## 8. 各方法理论容忍度（代码 `TOLERANCE` 常量中同步记录）

| 聚合器 | 恶意方容忍上限 |
|---|---|
| fedavg | 0% |
| clip_avg | 无方向防护，仅限制破坏幅度 |
| krum / multi_krum | < (n−2)/2 ≈ 40%，合谋超限时反而投出恶意更新 |
| trimmed_mean / coord_median | 每维 < 50% |
| fltrust | 不受比例硬约束，依赖根数据代表性 |
| adaguard | 簇上限使合谋退化为 2 票，可抗 >50% 同向合谋（受根锚质量约束） |

## 9. 工程注意事项

- 所有 48 组共用同一份数据切分、同一组恶意方编号、同一初始化种子，
  差异只来自攻击与聚合器，保证可比；
- 恶意标签 `is_malicious` 仅用于 TPR/FPR 统计，聚合函数内部不读取；
- 随机数按 `base_seed + 轮次×101 + 客户端编号` 确定性派生，可完整复现；
- 每个聚合器在**自己的全局轨迹**上实时本地训练（精确模式）。
  `ScenarioCache` 提供了基于 fedavg 参考轨迹的预计算快速模式，
  但因轨迹近似会影响攻防对比的严谨性，正式实验默认不启用。

## 10. 预实验中实测确认的关键失效模式（30 轮完整结果见 `results/report.md`）

1. **Krum 在 40% 合谋下被接管**：4 家合谋者两两距离接近 0，
   Krum 分数反而最低而被选中，受害类召回崩到接近 0，准确率仅 0.53。
   这复现了文献中 Krum 的 f < (n−2)/2 前提被违反时的经典失败。
2. **FLTrust 挡不住长期后门累积**：12 轮时后门 ASR 还是 0，
   30 轮时升到 0.99——后门更新与根更新正相关（学主任务的同时夹带触发器），
   余弦信任分给正权重，触发器分量逐轮累积最终学入模型。
   AdaGuard 的 L3 坐标截断每轮清除残余分量，同场景 ASR 保持 ≈0.02。
3. **纯范数防御对定向攻击无效**：clip_avg 在后门场景 ASR=1.0，
   因为攻击者把范数伪装到中位数的 1.5 倍，裁剪阈值根本不触发；
   必须叠加方向层（L2）才能识别。
4. **坐标中位数在非 IID 下收敛明显变慢**：良性场景 30 轮准确率仅 0.81，
   逐坐标取中位数会系统性低估更新幅度，是鲁棒性对精度的隐性税。
5. **AdaGuard 的良性代价约 1.3 个百分点**（0.993 → 0.980），
   是所有带防御方法中除 clip/trimmed_mean 外最低的，
   而它在 5 个攻击场景下的受害类召回与后门 ASR 均为最优或并列最优。

## 11. 单元测试与消融

```bash
.venv/bin/python -m robust_fl.tests       # 15 项数学不变量/攻击构造测试
.venv/bin/python -m robust_fl.ablation    # AdaGuard 逐层消融, 输出 results/ablation.csv
```

消融变体包含：逐层关闭 L1/L2/L3/L4、去掉软步长上限、
以及"L2-only"（近似无对齐的 FLTrust），用于量化每一层的独立边际贡献。
